# Обновление генерации на восстановленном VPS

Цена новых заказов генерации — 150 ₽ до применения промокодов. Уже созданные
заказы сохраняют записанную стоимость. Баннер генерации расположен над списками
инструкций на главной и в каталоге. На каждой странице выводятся 12 инструкций.

## Установка

`update-generation.sh` предназначен для восстановленного сервера BoykovDocs:
исходники в `/opt/boykovdocs/app`, Compose в `/opt/boykovdocs/docker-compose.yml`,
контейнеры `boykovdocs-api` и `boykovdocs-nginx`, образ API `boykovdocs-api:recovery`.
Это самостоятельный установщик с проверяемым снимком двенадцати исходных файлов;
он принимает исходную или уже обновлённую версию каждого файла. При других
изменениях файлов установка останавливается до их замены.

Скопируйте скрипт на сервер и выполните под root:

```bash
bash /root/boykovdocs-generation-update.sh
```

Клиент собирается в Node 22. Помимо `client`, контейнер получает каталог
`server/src/shared` только для чтения: клиент импортирует из него общие модули.
Вывод сборки сохраняется в `frontend-build.log` внутри контрольной точки.

Перед изменениями создаётся каталог
`/root/boykovdocs-restore/pre-generation-update-XXXXXX` с исходниками, прежним
HTML и идентификатором образа API. После сборки скрипт проверяет цену через API,
значения окружения, публичные ресурсы и HTTPS. При ошибке возвращает исходники,
HTML и образ API, если соответствующий этап уже выполнялся.

Успешный результат:

```text
GENERATION_PRICE_RUB=150
GENERATION_BANNER=ABOVE_INSTRUCTION_LISTS
INSTRUCTIONS_PER_PAGE=12
GENERATION_UPDATE=OK
```

## Проверки

`npm run quality:check`: форматирование, ESLint, тесты конфигурации линтера,
874 серверных теста и production-сборка клиента — успешно.

Отдельно проверены создание нового заказа за 150 ₽ и неизменность старого заказа
за 500 ₽. Для изолированной сборки воспроизведена ошибка без `server/src/shared`
и подтверждена успешная сборка после подключения этого каталога.

После установки проверьте расположение баннера на компьютере и телефоне.
